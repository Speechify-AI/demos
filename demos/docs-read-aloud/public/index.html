Getting started with Acme

Welcome to Acme. This guide walks you through your first integration. We keep it short — most teams are up and running in under ten minutes.

Install

Add the package to your project, configure an environment variable with your API key, and you are ready to go.

npm install @acme/sdk
# export ACME_API_KEY=sk_live_...

Make your first call

Create a client, call the method, and handle the result. Everything is synchronous unless you opt into streaming.

const client = new Acme({ key: process.env.ACME_API_KEY });
const result = await client.things.create({ name: "first-thing" });
console.log(result.id);
