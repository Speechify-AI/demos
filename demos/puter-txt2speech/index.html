Speechify TTS in Puter

Speaks with a Speechify Simba 3.2 voice through puter.ai.txt2speech() — no API key, no backend. Puter asks you to sign in on the first call; usage bills to your Puter account.

Requires a Puter build that includes the Speechify TTS driver (merged upstream July 2026). An unknown-provider error means this Puter instance predates it — or, on a self-hosted instance, that no Speechify API key is configured in its TTS driver config (the provider isn't registered without one).
